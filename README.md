# systolic-mac-1x4

我的第一个数字 IC 前端设计：一个 1×4 脉动阵列乘加行，用 Verilog 实现 4 维内积 `y = W·x`。

2026-11-08 完成，从规格、RTL、验证到逻辑综合走完了完整的数字前端流程。这个仓库是我这次设计的完整记录。

## 设计概要

- 结构：4 个 MAC PE 级联成一行，weight-stationary（权重预载进 PE 后保持不动）
- 数据：8 位无符号输入，24 位无符号累加；满量程用例 4×255×255 = 260100，不溢出
- 数据流：x 逐拍从左端流入、每 PE 前进一级；部分和沿 PE 链传递，每 PE 走两级寄存器——两条链速度差一倍，x 和它对应的部分和才能在每个 PE 准时相遇（时序对齐方案见 `docs/spec.md`）
- 时序：权重预载 4 拍，送入 x 4 拍；以采样到 x0 的时钟沿为第 0 拍，`done` 在第 8 拍拉高、只持续 1 拍，此时 `y_out` 有效
- 复位：`rst_n` 低有效异步复位
- 一次只算一组，不做连续流

## 流程与结果

1. **规格**：先定规格再写代码。关键决策由我拍板：时序对齐用「部分和两级寄存器」方案、数据用无符号（为了能用全 255 用例验满量程）、一组一组算、异步低有效复位。见 `docs/spec.md`（设计前定稿，含拍级时序表）。
2. **RTL**：`rtl/mac_pe.v`（单个 PE）+ `rtl/systolic_row.v`（顶层：权重装载计数器、x_valid 门控、done 移位寄存器）。
3. **验证**：先用 Python 写金标准（`golden/gen_golden.py`）算期望值，再写自检 testbench（`tb/tb_systolic_row.v`，在时钟下降沿采样）。4 个定向用例（含全 255 满量程、含 0 权重）**全部通过，ALL PASS**：70 / 260100 / 51 / 4。我还让它故意造了三个坏掉的设计（done 晚一拍、done 不来、结果差 1），验证 testbench 真能抓错——三个都正确报了 FAIL。
4. **综合**：yosys 通用综合（无工艺库），得门级网表和资源报告：**1859 个单元、227 个触发器、0 个 latch、0 个组合环、0 条警告**。触发器数目和 RTL 寄存器位宽逐位对过账：RTL 共 292 位，综合削掉 57 位恒为 0 的部分和高位和 8 位无用寄存器，正好 227。对账过程见 `docs/synthesis_report.md`。

详细文档在 `docs/`：设计说明（含从波形里逐拍提取的数据流表）、验证报告（含原始仿真输出和未测项清单）、综合报告。

## 一键复现

需要 [OSS CAD Suite](https://github.com/YosysHQ/oss-cad-suite-build)（iverilog + yosys）。默认路径 `C:\oss-cad-suite`，装在别处时先设环境变量 `OSS_CAD`。

```bash
bash sim/run.sh          # 重新生成金标准 → 编译 → 仿真，期望结尾 ALL PASS、退出码 0
bash synth/run_synth.sh  # 逻辑综合，报告写入 synth/synth_report.txt
```

## 目录

- `rtl/` — Verilog 源码
- `tb/` — 自检 testbench
- `golden/` — Python 金标准脚本与生成的用例文件
- `sim/` — 仿真脚本、波形（VCD）
- `synth/` — 综合脚本、网表与报告（`out/` 为工具原始产出）
- `docs/` — 规格、设计说明、验证报告、综合报告

## 如实说明（没做的事）

- 没挂工艺库，所以没有面积、时序和功耗数字；综合是通用综合
- 没做门级仿真
- 验证只有 4 个定向用例，没做随机测试和覆盖率统计
- 这些未做项在 `docs/verification_report.md` 里也逐条列了
